4. MRI Scan Upload & Disease Classification Flow

Workflow 04
The core pipeline of the application: 1. Client uploads an MRI image. 2. Server validates the user, saves the original image, and passes it to the BrainMRIPredictor engine. 3. Preprocessing applies CLAHE histogram equalization, unsharp masking, resizing (96x96), and normalizes pixels. 4. Inference runs on the hybrid CNN+BiLSTM deep learning model (or outputs high-fidelity mock classes if Tensorflow is absent). 5. Grad-CAM calculations map neural activation regions. 6. Heatmap is blended with the original MRI, saved, and records are stored in the database.

14. Grad-CAM Visualization Flow

Workflow 14
The internal, backend pipeline in prediction.py executing class activation mapping (Grad-CAM). It extracts the last convolutional layer, sets target class gradients, and blends the resulting colorized visual intensity map with the raw input MRI.
sequenceDiagram autonumber participant BE as "FastAPI Server (main.py)" participant PE as "Predictor Engine (prediction.py)" participant TF as "TensorFlow / Keras API" participant ML as "CNN+BiLSTM Model (.h5)" participant CV as "OpenCV Library" BE->>PE: Trigger generate_heatmap(raw_img, preprocessed, predicted_class) activate PE alt TensorFlow is installed & Model is loaded (Real Grad-CAM) PE->>ML: Traverse layers in reverse to find last Convolutional Layer PE->>PE: Get target class index from class_names.npy PE->>TF: Create Gradient Tape model w/ inputs [model.inputs] & outputs [conv_layer.output, model.output] activate TF PE->>TF: Record forward pass w/t target class index loss TF->>PE: conv_outputs, predictions PE->>TF: Compute gradients: tape.gradient(loss, conv_outputs) TF-->>PE: Gradients matrix deactivate TF Note over PE: 1. Apply ReLU filtering on gradients
2. Compute spatial average pooling for channel weights
3. Compute weighted linear sum of feature channels
4. Apply ReLU & normalize map to [0, 1]
5. Resize map to match raw_img dimensions else TensorFlow is absent (Fallback Anatomical Generator) PE->>CV: Convert raw image to grayscale PE->>CV: Apply binary thresholding & retrieve contours Note over PE: Find largest contour (brain outline) and bounding box Note over PE: Calculate anatomical temporal & hippocampal centers PE->>PE: Draw Gaussian hotspots over temporal lobes and central ventricles PE->>PE: Normalize intensity map to [0, 1] end PE->>CV: Apply JET Colormap (COLORMAP_JET) to [0, 255] intensity map CV-->>PE: RGB Heatmap overlay matrix PE->>CV: Blend raw_img (0.65 weight) with heatmap (0.35 weight) CV-->>PE: Blended Grad-CAM image matrix PE-->>BE: Return blended Grad-CAM image matrix deactivate PE
